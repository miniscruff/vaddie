## v0.7.0 on 2026-11-09

### ✨ Added

* [#56](https://github.com/miniscruff/vaddie/issues/56) TimeBeforeEq validation
* [#56](https://github.com/miniscruff/vaddie/issues/56) TimeAfterEq validation
* [#62](https://github.com/miniscruff/vaddie/issues/62) TimeBeforeNow validation
* [#62](https://github.com/miniscruff/vaddie/issues/62) TimeAfterNow validation
* [#62](https://github.com/miniscruff/vaddie/issues/62) TimeBeforeFromNow validation
* [#62](https://github.com/miniscruff/vaddie/issues/62) TimeAfterFromNow validation

### 🔥 Changed

* [#59](https://github.com/miniscruff/vaddie/issues/59) Minimum Go version is now 1.26
* [#58](https://github.com/miniscruff/vaddie/issues/58) IfExp is no longer experimental and is renamed to If
* [#56](https://github.com/miniscruff/vaddie/issues/56) TimeBefore and TimeAfter no longer accept a time equal to the bound, use TimeBeforeEq or TimeAfterEq

### 🪲 Fixed

* [#55](https://github.com/miniscruff/vaddie/issues/55) TimeEq now compares instants, so the same time in different locations is equal
